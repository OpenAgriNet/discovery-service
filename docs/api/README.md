# API artefacts

Two files, and they answer different questions.

| File | What it is | Scope |
|---|---|---|
| [`openapi.yaml`](openapi.yaml) | OpenAPI 3.0.3, hand-written | **Three surfaces** — this service's `/publish` and `/discover`, the registry's REST tables, and a provider node's `/select` |
| [`openagrinet.postman_collection.json`](openagrinet.postman_collection.json) | Postman, hand-kept | **This service only** — one publish and four discover calls against `localhost:8080` |

## `openapi.yaml`

The network's three surfaces in one document, because a caller doing anything
useful crosses all three: discover here, resolve in the registry, select at the
provider node. Every path carries its own `servers` block, so the host is
unambiguous per operation and the single file is not claiming they share one.

| Surface | Host | Auth | Tags |
|---|---|---|---|
| Discovery | `discovery-network-vistaar.da.gov.in` | handled by the adapter in front | Publish, Discover |
| Registry | `registry-network-vistaar.da.gov.in` | bearer | SchemaRegistry, Participant, ProviderSchema |
| Provider node | `provider-network-vistaar.da.gov.in` | Beckn request signature, verified by the adapter | Select |

**It is not the protocol contract.** `Catalog`, `Provider`, `Resource` and
`Offer` are declared permissively here; the authoritative shapes are in
`tests/testdata/beckn-v2.0.0.yaml`, which is what this service actually
validates every request and response against at runtime. Where the two disagree,
`beckn.yaml` wins — and the disagreement is a bug in this file.

**Every operation is synchronous.** The outcome is the `200` body; `on_discover`
and `on_select` are response shapes, not callback endpoints. See
[`../registry.md`](../registry.md#synchronous-and-the-spec-has-not-caught-up)
for why that deviates from the published v2.0.0 schema and why it is a decided
deviation rather than a defect.

## `openagrinet.postman_collection.json`

Five requests: publish the sample catalog, then find it four ways — free text,
spatial, JSON filter, and all three combined. `baseUrl` defaults to
`http://localhost:8080`. Bring a stack up with `make run` or follow
[`../quickstart.md`](../quickstart.md), then run Publish first.

**This is not the collection `make newman` runs.** That one is
`examples/OpenAgriNet-discovery-service.postman_collection.json`, generated by
`examples/build-postman.py` from the numbered request files in `examples/`, and
it asserts the exact set of resource ids each request returns. This one is for
reading and poking at; that one is a gate. See
[`../../examples/README.md`](../../examples/README.md) for what each case pins.
